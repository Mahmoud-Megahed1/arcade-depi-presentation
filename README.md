# Arcade Electronics — Capstone Presentation Deck

An interactive presentation deck and database architecture reference for the Arcade Electronics e-commerce platform, prepared for the Digital Egypt Pioneers Initiative (DEPI / MCIT) capstone evaluation.

## Project Structure

`
arcade-depi-presentation/
├── index.html          # Main presentation document with interactive slides
├── styles.css          # Dark-mode responsive styling
├── script.js           # Navigation controller and keyboard handlers
├── erd-diagram.png     # Entity Relationship Diagram (ERD)
├── schema-diagram.png  # Relational Database Schema Diagram
└── README.md           # Documentation
`

## Presentation Features

- **Slide Deck Structure**: Comprehensive breakdown of problem statements, architecture, MVC request pipeline, ERD schema, and security considerations.
- **Controls**: Full keyboard navigation (Arrow keys, Space, PageUp/PageDown, Home/End, F for Fullscreen) and mobile swipe support.
- **Database Architecture**: Embedded high-resolution ERD and relational schema diagrams.

## Technology Stack

- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Google Fonts (Inter)
- Font Awesome Icons
