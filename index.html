Problem Statement

  • Traditional electronics shopping is limited by physical store locations and operating hours, creating inconvenience for customers.
  • Customers lack convenient online options to browse, compare, and purchase electronic products from the comfort of their homes.
  • Retailers need efficient systems to manage inventory, track orders, and maintain product catalogs without manual overhead.
  • This gap creates inefficiencies, reduces accessibility, and hinders the overall shopping experience for all stakeholders.

Database Design

Relational database using Microsoft SQL Server, managed via Entity Framework Core.

Key Entities

  • User: Stores email, password hash, full name, role (Customer/Admin), and active status. Linked to CartItems and Orders.
  • Category: Contains category name. Linked to Products (one-to-many).
  • Product: Stores name, price, stock quantity, description, and image URL. Linked to Category, CartItems, and OrderDetails.
  • CartItem: Links User to Product with quantity. Enables persistent shopping cart.
  • Order: Stores order date, total amount, status (Pending/Completed), and delivery address. Linked to User and OrderDetails.
  • OrderDetail: Junction table linking Order to Product with quantity and unit price.
Data Flow: Data collected via user inputs on Razor Pages; stored in SQL Server using EF Core; accessed through Repository Pattern ensuring clean architecture.

Security & Data Protection

Authentication

  • BCrypt hashing with salt for passwords
  • JWT tokens with 24-hour expiration
  • Role-based access control (Customer/Admin)
  • Session timeout after inactivity

Data Protection

  • HTTPS/TLS encryption for all traffic
  • Encrypted connection strings
  • No credit card storage (simulated checkout)
  • Minimal personal data collection

Injection Prevention

  • Entity Framework parameterized queries
  • Server-side input validation
  • HTML encoding for XSS prevention
  • Email format validation (RFC 5322)

Access Control

  • Anti-CSRF tokens on all forms
  • Admin-only protected controllers
  • User-specific data access only
  • ASP.NET Core auth middleware
